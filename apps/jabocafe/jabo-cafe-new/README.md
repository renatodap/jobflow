# Jabô Café - Réplica em React

Este projeto é uma réplica completa do site oficial da Jabô Café (https://jabo.cafe) desenvolvida em React/Next.js.

## 🎯 Objetivo

Replicar fielmente o design, layout, cores, fontes e conteúdo do site original da Jabô Café, mantendo todas as informações e ativos visuais.

## ✅ Características Implementadas

### Design e Layout
- ✅ Header com navegação colorida (cada item com cor específica)
- ✅ Hero section com fundo laranja/amarelo gradiente
- ✅ Seção de tradição com vista aérea da fazenda
- ✅ Seção "Experimente o Sabor" com fundo marrom
- ✅ Seção de depoimentos com fundo bege
- ✅ Jornada de excelência com 4 etapas coloridas
- ✅ Blog com 3 artigos
- ✅ Seção de contato com formulário
- ✅ Footer completo com 4 colunas

### Cores Originais

## 🚀 Como Executar

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou pnpm

### Instalação
```bash
# Clonar o repositório
cd jabo-cafe-replica

# Instalar dependências
npm install
# ou
pnpm install

# Executar em modo desenvolvimento
npm run dev
# ou
pnpm run dev
```

O site estará disponível em `http://localhost:5173`

### Build para Produção
```bash
# Gerar build de produção
npm run build
# ou
pnpm run build

# Visualizar build
npm run preview
# ou
pnpm run preview
```

## 🛠️ Tecnologias Utilizadas

- **React 18** - Biblioteca principal

## 🎨 Detalhes de Design

### Header
- Navegação com cores específicas para cada seção
- Logo posicionado à esquerda
- Seletor de idioma à direita

### Hero Section
- Fundo gradiente laranja/amarelo
- Layout em duas colunas
- Imagens da fazenda e proprietários
- Card lateral com informações

### Seções Principais
1. **Tradição** - Fundo branco com imagens da fazenda
2. **Sabor** - Fundo marrom com vídeo
3. **Depoimentos** - Fundo bege com cards de clientes
4. **Jornada** - 4 etapas com cores específicas
5. **Blog** - 3 artigos com imagens
6. **Contato** - Formulário com fundo marrom

## 📱 Responsividade

O site é totalmente responsivo e se adapta a diferentes tamanhos de tela:
- **Desktop**: Layout completo em grid
- **Tablet**: Adaptação de colunas
- **Mobile**: Layout em coluna única
