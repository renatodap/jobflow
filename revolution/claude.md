## PRD (Product Requirements Document)

### Problem Statement
Content creators, influencers, and marketers lack early access to trending topics and struggle to consistently produce viral content, often missing opportunities because they discover trends too late and don't have proven content strategies.

### Jobs-to-be-Done
1. **Primary Job**: Get early intelligence on trending topics before mainstream adoption (6-12 hours ahead)
2. **Secondary Job**: Receive proven content formats, hooks, and viral templates for each trend
3. **Supporting Job**: Access curated insights and performance data on what content formats work best

### Target Users (STEALTH POSITIONING)
- **Primary**: "Elite content creators" seeking exclusive intelligence (100M+ globally, $104B creator economy)
- **Secondary**: Marketing professionals wanting competitive advantage (5M+ professionals)  
- **Tertiary**: Newsletter creators and thought leaders (10M+ active)

### Core v0.1 Feature Set (Strictly Minimal)
1. **Trending Topic Detection**: Real-time trending topics from Twitter, Reddit, Google Trends
2. **AI Content Generator**: One-click transformation of topics into:
   - Engaging text summaries (Twitter threads, LinkedIn posts)
   - Shareable images (quotes, infographics, memes)
   - Short video scripts with AI voiceover
3. **Multi-Format Export**: Download content for Instagram, TikTok, Twitter, LinkedIn
4. **Social Scheduler**: Schedule posts across platforms with optimal timing
5. **Viral Score Predictor**: AI predicts content viral potential (0-100 score)
6. **Content Gallery**: Browse and remix top-performing content from community

### Non-Goals (Prevent Scope Creep)
- Full video editing suite
- Advanced analytics dashboard
- Team collaboration features
- Custom branding options
- API integrations (v1 only)
- Multi-language support
- Advanced automation workflows

### Monetization Plan
**Freemium + Ads + Affiliates Model**:
- **Free**: 5 pieces of content/day, basic templates, TrendCraft watermark, ads between content
- **Pro ($9.99/month)**: 50 content pieces/day, premium templates, no ads, viral score predictor
- **Creator ($29.99/month)**: Unlimited content, custom templates, social scheduler, priority support

**Additional Revenue Streams** (85% companies use affiliate marketing for high ROI):
- **Affiliate Partnerships**: Content creation tools, stock photo sites, social media tools (30% commission)
- **Sponsored Content**: Brands pay to have their products integrated into trending content
- **Premium Templates**: User-generated templates marketplace (20% commission)

**Paywall Moments**:
1. 6th piece of content in a day (upgrade to Pro)
2. Viral score predictor access (Pro feature)
3. Social scheduler (Pro feature)

### Virality Plan
1. **Built-in Viral Content**: Every piece of content is designed to be shared
2. **Social Proof**: "Generated with TrendCraft AI" attribution drives traffic
3. **Content Challenges**: Weekly viral content challenges with prizes
4. **Influencer Program**: Top creators get revenue sharing for driving signups
5. **SEO Powerhouse**: Trending topics = high search volume content
6. **Network Effects**: More users = better trending topic detection = more value

**Share Loops** (MASSIVE VIRAL POTENTIAL):
- User creates viral content → Content gets shared → Attribution drives signups → More users create more content → Better trend detection → Higher quality content → More shares

## Architecture & Principles

### Tech Stack Justification
- **Frontend**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
  - *Rationale*: Fastest development, built-in SEO, edge deployment ready
- **Backend**: Next.js API Routes + Prisma ORM + PostgreSQL
  - *Rationale*: Unified codebase, rapid prototyping, strong typing
- **AI Content**: OpenAI GPT-4 for text + DALL-E 3 for images + ElevenLabs for voiceover
  - *Rationale*: Best quality multimodal content generation, reliable APIs
- **Trending Data**: Twitter API v2 + Reddit API + Google Trends API + News API
  - *Rationale*: Real-time trending topic detection across platforms
- **Image Processing**: Fabric.js for meme generation + Canvas API for dynamic graphics
  - *Rationale*: Client-side image manipulation, fast rendering
- **Social Integration**: Social media APIs for cross-platform posting + scheduling
  - *Rationale*: Direct social distribution, optimal timing algorithms
- **Payments**: Stripe + Google AdSense + Affiliate tracking
  - *Rationale*: Multiple revenue streams, proven monetization
- **Hosting**: Vercel (frontend) + PlanetScale (database) + Cloudflare (CDN)
  - *Rationale*: Global scale, edge computing, content delivery optimization

### Data Model Sketch
```prisma
model User {
  id            String   @id @default(cuid())
  email         String   @unique
  subscription  String?  // free, pro, creator
  dailyContent  Int      @default(0) // Track daily usage
  contentPieces Content[]
  createdAt     DateTime @default(now())
}

model Content {
  id           String   @id @default(cuid())
  type         String   // text, image, meme, video_script
  topic        String   // Original trending topic
  content      Json     // Generated content data
  viralScore   Int?     // AI-predicted viral score (0-100)
  actualShares Int      @default(0) // Real share count
  platform     String[] // Target platforms
  userId       String
  user         User     @relation(fields: [userId], references: [id])
  createdAt    DateTime @default(now())
}

model TrendingTopic {
  id          String   @id @default(cuid())
  topic       String   @unique
  source      String   // twitter, reddit, google_trends, news
  volume      Int      // Trend volume/mentions
  growth      Float    // Growth rate
  category    String   // tech, entertainment, news, etc.
  updatedAt   DateTime @updatedAt
}
```

## Operating System (OS) for Building

### Loop Protocol: PLAN → DO → VERIFY → DOCUMENT → NEXT
1. **PLAN**: Read current Next Action from Roadmap
2. **DO**: Execute exactly one atomic action
3. **VERIFY**: Run tests, check against acceptance criteria
4. **DOCUMENT**: Update claude.md with results and evidence
5. **NEXT**: Write next single-sentence imperative action

### Commit Protocol
- **Format**: Conventional Commits (feat/fix/docs/test/refactor)
- **Reference**: Include claude.md anchor link in commit body
- **Scope**: Single feature/component per commit
- **Tests**: All tests pass before commit

### Release Protocol
- **Feature Flags**: PostHog feature flags for new features
- **Tiny Releases**: Deploy single features, not batches
- **Rollback Plan**: Feature flag disable + database rollback scripts
- **Monitoring**: 15-minute post-deploy health check
