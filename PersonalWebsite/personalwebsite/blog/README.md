# Blog Support Directory

This folder contains blog helpers, documentation, scripts, and automation tools — not the posts themselves.

**Posts location:** MDX posts live in `/content/posts/yyyy/mm/slug.mdx`

**This directory contains:**
- Helper scripts for content generation and validation
- Documentation for the AI-Daily blog system
- Automation tools, utilities, and workflow specs
- Brand assets and templates
- Prompt library for content generation

**Key pages:**
- Blog homepage: `/blog`
- Methodology: `/blog/methodology` (authored via MDX)
- Approval dashboard: `/blog/admin` (internal)
