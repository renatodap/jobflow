# LinkedIn Native Post Format

## Structure
**Length:** 120-180 words + 3 decision bullets
**Frequency:** Tuesday & Friday
**Time:** Flexible (peak engagement 8-10 AM ET)

## Template

```
[Hook - surprising statement or data point]

[Context - why this matters now, 2-3 sentences]

[Main insight - what changed or what you learned, 2-3 sentences]

[Practical application - what reader can do, 1-2 sentences]

Here's my framework:

• [Decision point 1]: [Do this when X, avoid when Y]
• [Decision point 2]: [Choose A for speed, B for quality]  
• [Decision point 3]: [Worth it if X, skip if Y]

[Call to action - usually "What's your experience with X?"]

[Hashtags - 3-5 relevant ones]
```

## Example Post

```
AI coding assistants now write 40% of production code at Google. But they're making debugging 3x harder.

The problem isn't the AI-generated code quality. It's that developers don't fully understand code they didn't write. Microsoft found bug fix time increased from 2 hours to 6 hours average when working with AI-generated codebases.

The solution isn't avoiding AI. It's changing how we use it.

My new framework:

• Generate small functions only: <50 lines at a time
• Always write tests first: AI fills implementation
• Review like it's someone else's PR: assume nothing

We're optimizing for writing speed when we should optimize for reading speed.

What's your rule for AI-generated code limits?

#AIEngineering #CodingProductivity #SoftwareDevelopment #TechLeadership #DeveloperTools
```

## Style Rules
- No emojis in main text
- Bullet points for scanability
- One number/stat in first line
- Contrarian angles perform best
- End with open question

## Topics That Perform
1. Counter-intuitive findings
2. Tool comparisons with numbers
3. Workflow optimizations
4. Failure stories with lessons
5. Industry changes affecting everyone

## Topics to Avoid
- Theoretical AI futures
- Vendor announcements
- Technical deep-dives
- Political implications
- Hype without substance

## Engagement Tactics
- Respond to comments within 2 hours
- Ask follow-up questions
- Share others' related insights
- Create discussion not broadcast

## Tracking Success
- Baseline: 500+ impressions
- Good: 1,000+ impressions
- Excellent: 2,500+ impressions
- Viral: 10,000+ impressions

Watch for:
- Comments from target audience
- Reshares with commentary
- Profile views → followers
- InMail quality inquiries
