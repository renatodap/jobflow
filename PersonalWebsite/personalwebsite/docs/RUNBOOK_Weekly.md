## Emergency Procedures

**If buffer drops to 0:**
1. Run emergency scout: `/scout urgent`
2. Lower threshold to 60 temporarily
3. Recycle top 3 performers from last month
4. Manual write if needed (30 min)

**If YouTube script not ready:**
1. Compilation of week's top 3 posts
2. Focus on one deep-dive tool
3. 5-minute version acceptable

**If metrics not loading:**
1. Manual check each platform
2. Screenshot for records
3. Update sheet manually

## Time Optimization

**Templates save time:**
- YouTube intro/outro (save 5 min)
- LinkedIn bullet format (save 5 min)
- Validation test structure (save 10 min)

**Batch similar tasks:**
- Review all metrics at once
- Write all themes together
- Process all approvals in one session
