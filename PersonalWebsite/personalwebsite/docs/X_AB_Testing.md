# X (Twitter) A/B Testing Protocol

## Daily Schedule
**Post Time:** 3:00 PM ET (both hooks)
**Check Time:** 3:30 PM ET (first check)
**Decision Time:** 4:00 PM ET (delete loser)
**Platform:** X (formerly Twitter)

## Hook Types

### Hook A: Benefit-First
- Lead with outcome/benefit
- Specific number or metric
- What reader gains
- Positive framing

### Hook B: Contrarian/Problem-First  
- Challenge common belief
- Highlight what's broken
- Controversial take
- Negative framing

## Testing Process

### 3:00 PM - Post Both Hooks
1. Post Hook A as regular tweet
2. Wait 2 minutes (avoid shadowban)
3. Post Hook B as regular tweet
4. Do NOT quote-tweet or thread

### 3:30 PM - First Check
Record metrics:
- Hook A: Impressions, likes, replies, retweets
- Hook B: Impressions, likes, replies, retweets

### 4:00 PM - Final Decision
1. Calculate engagement rate: (likes + replies + retweets) / impressions
2. Delete the loser (lower engagement rate)
3. Optional: Reply to winner with thread content
4. Log results in tracking sheet

## Example A/B Test

**Topic:** AI code review tools

**Hook A (Benefit-first):**
"Cut code review time by 73% with this GitHub Action that catches what humans miss"

**Hook B (Problem-first):**
"Your code reviews are missing 40% of bugs. Here's what senior devs started using instead"

**Results at 4 PM:**
- Hook A: 523 impressions, 12 likes, 3 replies = 2.87% engagement
- Hook B: 498 impressions, 18 likes, 7 replies = 5.02% engagement
- **Winner: Hook B** (deleted Hook A)

## What Makes Hooks Win

**High performers include:**
- Specific numbers (73%, $200, 10 minutes)
- Contrarian takes that feel true
- Clear problem → solution arc
- Time-sensitive angles ("just released")
- David vs. Goliath stories

**Consistent losers:**
- Vague benefits
- Question hooks (unless rhetorical)
- Feature announcements
- "Here's how" openings
- Thread teasers

## Monthly Analysis

Track patterns:
- Benefit vs. Problem win rate
- Best performing numbers
- Optimal negative/positive ratio
- Time-of-day variations
- Day-of-week patterns

## Advanced Tactics

### Multi-variant testing (monthly)
Once monthly, test 3-4 hooks:
- Post all within 10 minutes
- Check hourly for 4 hours
- Delete all but winner
- Higher sample size = better data

### Follower quality check
Winners should attract:
- Target audience (check profiles)
- Thoughtful replies (not just "nice!")
- Quote tweets with additions
- Profile visits → follows

## Common Mistakes

1. **Testing different topics** - Only test hook style, not content
2. **Posting too close** - Wait 2+ minutes between posts
3. **Leaving losers up** - Always clean up for feed quality
4. **Not tracking patterns** - Data without analysis is waste
5. **Ignoring reply quality** - Engagement rate isn't everything

## Tools

## Success Metrics

- **Good test:** 15%+ difference in engagement
- **Great test:** 30%+ difference
- **Excellent test:** 50%+ difference
- **Monthly goal:** 20+ completed tests
- **Win rate target:** Identify 3-5 patterns

Remember: Every test teaches something, even "failures"
