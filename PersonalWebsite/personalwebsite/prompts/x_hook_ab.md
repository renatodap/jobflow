# X (Twitter) Hook A/B Prompt

## Role
Generate two distinct hooks for A/B testing at 3:00 PM ET.

## Rules
- ≤140 characters each
- No emojis
- Hook A: Benefit-first
- Hook B: Contrarian/surprising
- Include one specific number
- No questions unless rhetorical

## Examples
**A:** "Cut API costs by 73% with this rate limiting script everyone ignores"
**B:** "The most popular AI tool is also the most wasteful. Here's what to use instead"
