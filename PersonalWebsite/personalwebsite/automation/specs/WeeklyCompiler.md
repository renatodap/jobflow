# Weekly YouTube Compiler Specification

## Overview
Transform the week's best content into compelling 8-10 minute YouTube videos with teleprompter-ready bullets (not prose).

## Schedule
- **Compilation:** Sunday 2:00 PM ET
- **Review:** Sunday 4:00 PM ET
- **Recording:** Monday morning
- **Editing:** Monday afternoon
- **Upload:** Tuesday evening
- **Publish:** Wednesday 10:00 AM ET

## Input Sources

### Primary Content
1. **Top 3 blog posts** by engagement
2. **Best performing X hooks** (winners only)
3. **LinkedIn post** with most discussion
4. **Saturday's mini-validation** results

### Metrics to Include
- View counts
- Engagement rates
- Surprising findings
- User questions from comments

## Script Structure

### 1. Cold Open (15 seconds)
**Purpose:** Hook with surprising stat or finding
**Format:** 4 punchy bullets
**Example:**
```
- Microsoft devs waste 3.5 hours/week on AI
- Tested 50 tasks free vs paid
- 90% work on free tier
- Here's what matters
```

### 2. Title Card (5 seconds)
**Format:** "AI Reality Check: Week of [Date]"

### 3. Framework Section (2-3 minutes)
**Purpose:** Deep dive on week's best framework/pattern
**Structure:**
- Pattern identification
- Supporting data (3 points)
- Real example
- Solution steps
- Measurable outcome

### 4. Synthesis Section (2-3 minutes)
**Purpose:** Comparison or compilation of insights
**Structure:**
- Setup the comparison
- Options analyzed
- Results with numbers
- Clear winner/recommendation

### 5. Do This Today (1-2 minutes)
**Purpose:** Immediate actionable steps
**Structure:**
- 3 specific tasks
- Exact steps for each
- Time required
- Expected outcome

### 6. Changed My Mind (30 seconds)
**Purpose:** Show intellectual honesty
**Structure:**
- What I assumed
- What data showed
- Key learning

### 7. CTA & End Screen (15 seconds)
**Purpose:** Drive subscriptions and traffic
**Structure:**
- Subscribe reminder
- Blog link
- Next week teaser

## Teleprompter Format Rules

### Formatting
```
CAPS - Emphasis words
[PAUSE] - Dramatic pause
→ - Indicates flow/sequence
• - Bullet point
— - Em dash for aside
... - Natural trailing off
```

### Bullet Guidelines
- 2-4 words per line average
- Fragment sentences only
- Numbers prominent
- Active voice
- Natural pause points

### Example Bullet Set
```
DATA POINT: 73% fail here
[PAUSE]
Why? Cognitive overload
→ After 10 minutes
→ Quality drops fast
→ From 80% satisfaction
→ To just 12%
SOLUTION: Hard stop
Set timer — 10 minutes max
[PAUSE]
Save, step back, restart
RESULT: 4x faster completion
```

## Shot List Planning

### A-Roll (Direct to Camera)
1. Cold open - High energy
2. Transitions - Thoughtful pace
3. Changed mind - Reflective
4. CTA - Confident close

### B-Roll Requirements
1. Screen recordings of actual tools
2. Charts/graphs from data
3. Before/after comparisons
4. Code examples (if applicable)
5. Website/blog screenshots

### Graphics Needed
- Title card
- Section transitions
- Data visualizations
- Framework diagrams
- End screen template

### Script Review
- [ ] No complete sentences
