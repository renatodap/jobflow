Stop wasting tokens on back-and-forth clarifications. These five prompt templates get you precise results on the first try.

## The Hidden Cost of Bad Prompts

Every vague prompt costs you:
- 3-5 extra iterations at $0.02 per round
- 10 minutes of reformulating questions
- Inconsistent results you can't replicate

Last week I tracked 50 ChatGPT sessions. Average clarification rounds: 4.2. Total wasted: 3.5 hours and $8.40.

## The 5-Template System

### Template 1: The Analyzer
```
Role: You are a [specific expert type]
Context: [2-3 sentences of background]
Input: [paste your data/text]
Analysis needed: [specific metrics/insights]
Output format: [bullet points/table/summary]
Constraints: [length/style/exclusions]
```

**When to use:** Data analysis, document review, code debugging

### Template 2: The Builder
```
Build a [specific thing] that:
- Must include: [requirement 1, 2, 3]
- Must avoid: [anti-requirement 1, 2]
- Style: [formal/casual/technical]
- Length: [specific word/line count]
- Output format: [file type/structure]
Example of good output: [brief sample]
```

**When to use:** Content creation, code generation, templates

### Template 3: The Transformer
```
Transform this [input type]:
[paste input]

Into [output type] following these rules:
1. Preserve: [what to keep]
2. Change: [what to modify]
3. Add: [what to include]
4. Remove: [what to exclude]
Target audience: [who will use this]
```

**When to use:** Format conversion, style rewriting, translation

### Template 4: The Comparator
```
Compare these options:
Option A: [description]
Option B: [description]
Option C: [description]

Evaluation criteria (weight each):
- [Criterion 1]: 40%
- [Criterion 2]: 30%
- [Criterion 3]: 30%

Output: Ranked list with scores and one-line rationale
```

**When to use:** Decision making, tool selection, vendor evaluation

### Template 5: The Validator
```
Check this [content type] for:
[paste content]

Validation rules:
- Must have: [requirement list]
- Must not have: [prohibition list]
- Should follow: [best practice list]

Output: 
- Pass/fail for each rule
- Specific fixes needed
- Priority order (critical/important/nice-to-have)
```

**When to use:** Quality assurance, compliance checks, proofreading

## Common Pitfalls to Avoid

**The Kitchen Sink:** Don't combine multiple templates in one prompt. Run them sequentially instead.

**The Mind Reader:** Never use "improve this" without specifying exactly what improvement means.

**The Infinite Loop:** Set hard limits on iterations. If it's not right after 2 attempts, your template needs work.

## What I'd Do with 20 More Minutes

Create a prompt library in your notes app with these templates pre-filled for your common use cases. I keep 12 variations ready:

- Code review analyzer (Template 1 + specific language rules)
- Email transformer (Template 3 + tone guidelines)  
- Meeting notes builder (Template 2 + company format)
- Tool comparator (Template 4 + standard criteria)
- Contract validator (Template 5 + legal checklist)

Track which templates save the most time. After 30 days, optimize the top 3 for your specific needs.

Also consider using template variables: `{{LANGUAGE}}`, `{{TONE}}`, `{{LENGTH}}` that you can quickly find-replace based on context.
