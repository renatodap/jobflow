Microsoft's internal study just proved what we suspected: AI makes certain tasks measurably worse. Here's the decision tree that saves you from those traps.

## The Surprising Data

Microsoft tracked 5,000 employees using Copilot for 90 days:
- 23% of tasks took LONGER with AI assistance
- Error rates increased 4x for certain task types
- User satisfaction dropped 40% in specific categories

The pattern is clear once you see it.

## The 4-Minute Decision Tree

Ask these questions in order. First "no" means skip AI:

### Question 1: Is the correct answer knowable? (30 seconds)
**NO → Skip AI**
- Personal preferences
- Future predictions beyond data
- Subjective quality judgments

**YES → Continue**

### Question 2: Can you verify the output? (30 seconds)
**NO → Skip AI**
- Legal/financial advice
- Medical decisions
- Safety-critical instructions

**YES → Continue**

### Question 3: Is context bigger than 2 pages? (30 seconds)
**NO → Skip AI**
- Multi-document synthesis
- Long conversation history
- Complex system dependencies

**YES → Continue**

### Question 4: Is precision more important than speed? (30 seconds)
**YES → Skip AI**
- Final proofreading
- Financial calculations
- Technical specifications

**NO → Use AI**

### Question 5: Will you iterate more than twice? (2 minutes)
**YES → Skip AI**
- Complex creative vision
- Highly specific formatting
- Nuanced tone matching

**NO → Use AI**

## The 5 Tasks to Keep Manual

Based on the Microsoft data, never use AI for:

1. **Email to upset customers**
   - AI tone consistently wrong
   - Escalates 60% of conflicts
   - Missing emotional nuance

2. **Final budget numbers**
   - Hallucinated calculations
   - Invisible rounding errors
   - False confidence in wrong data

3. **Performance reviews**
   - Generic feedback patterns detected
   - Employees feel devalued
   - Legal liability issues

4. **Brand voice content**
   - Loses unique personality
   - Readers detect AI in 3 sentences
   - Engagement drops 45%

5. **Debug complex systems**
   - Suggests plausible-but-wrong fixes
   - Wastes hours on wild goose chases
   - Creates new bugs while "fixing"

## What Changed This Week

Three developments shifted the landscape:

**OpenAI's o1-preview:** Better at reasoning but 10x slower. Changes the speed/accuracy tradeoff.

**Anthropic's admission:** Claude now warns about multi-document limitations explicitly.

**Google's research:** Shows AI performs worse when users can't verify outputs independently.

## What I'd Do with 20 More Minutes

Build a personal task classifier:
1. List your 20 most common tasks
2. Run each through the decision tree
3. Tag as "AI-yes", "AI-no", or "AI-maybe"
4. Create keyboard shortcuts for AI-yes tasks
5. Track time saved vs. time wasted for 1 week

The surprising result: You'll find 3-4 tasks you thought were AI-perfect that actually work better manually. And 2-3 manual tasks that AI handles brilliantly.

## Do This Today

Test one task you always do manually:
1. Pick something small (5-minute task)
2. Run the decision tree
3. If it passes, try with AI
4. Compare: time, quality, stress level
5. Document the winner

Success metric: 20% time savings or skip it
